先完成[独立 JDBC 驱动的安装与连接](../../drivers/elastic/connection.mdx)。本页直接使用 JDBC，不要求使用 dbVisitor 上层 API。除示例自行创建连接外，`conn` 表示应用已打开并负责关闭的 JDBC 连接。

## 常用操作示例

### 1) 创建索引与 Mapping（DDL）
```java
try (Statement stmt = conn.createStatement()) {
    stmt.execute("PUT /my_index");
    stmt.execute("PUT /my_index/_mapping { \"properties\": { \"title\": { \"type\": \"text\" } } }");
}
```

### 2) 插入文档（DML）
```java
try (Statement stmt = conn.createStatement()) {
    stmt.executeUpdate("POST /my_index/_doc/1 { \"user\": \"kimchy\", \"message\": \"hello\" }");
}
```

### 3) 使用 `PreparedStatement` 查询（DQL）
```java
String dsl = "POST /my_index/_search { \"query\": { \"term\": { \"user\": ? } } }";
try (PreparedStatement pstmt = conn.prepareStatement(dsl)) {
    pstmt.setString(1, "kimchy");
    try (ResultSet rs = pstmt.executeQuery()) {
        while (rs.next()) {
            rs.getString("_ID");
            rs.getString("_DOC");
        }
    }
}
```

### 4) 路径占位符 `{?}`
```java
try (PreparedStatement pstmt = conn.prepareStatement("GET /my_index/_doc/{?}")) {
    pstmt.setString(1, "1");
    pstmt.executeQuery();
}
```

### 5) `_cat` 节点
```java
try (Statement stmt = conn.createStatement()) {
    stmt.executeQuery("GET /_cat/nodes");
}
```

## 多命令与 JDBC 结果

```java
try (Statement stmt = conn.createStatement()) {
    boolean hasResult = stmt.execute("GET /my_index/_count; HEAD /my_index");
    while (true) {
        if (hasResult) {
            try (ResultSet rs = stmt.getResultSet()) {
                while (rs.next()) {
                    System.out.println(rs.getObject(1));
                }
            }
        } else {
            long count = stmt.getLargeUpdateCount();
            if (count == -1) {
                break;
            }
            System.out.println("updated=" + count);
        }
        hasResult = stmt.getMoreResults(Statement.CLOSE_CURRENT_RESULT);
    }
}
```

查询使用 executeQuery；写入使用 executeUpdate 或 execute。多个命令以分号分隔，通过 execute/getMoreResults 读取，不等于 JDBC batch，也不构成事务。Hint 必须放在命令开头；完整 Hint 与限制见[命令参考](./commands.md)。

## 预读与结果列 {#pre-read}

`preRead=true` 默认预读结果并展开文档字段，同时保留 `_ID`/`_DOC`。关闭时按专用列读取原始文档；不要继续假设存在展开字段。preReadThreshold/preReadMaxFileSize 支持 B/KB/MB/GB；无单位按 MB，缓存目录默认 java.io.tmpdir。预读可能增加内存、磁盘和首行等待成本，并不是服务端分页上限。
