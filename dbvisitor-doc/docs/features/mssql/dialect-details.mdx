# SQL Server 方言细节

## 分页 SQL

SQL Server 使用 `ROW_NUMBER()` + CTE 实现分页：

```sql
WITH selectTemp AS (
  SELECT TOP 100 PERCENT ROW_NUMBER() OVER (ORDER BY CURRENT_TIMESTAMP) as __row_number__, *
  FROM 原始查询
)
SELECT * FROM selectTemp
WHERE __row_number__ BETWEEN ? AND ?
ORDER BY __row_number__
```

当原始查询已有 `ORDER BY` 时，`ROW_NUMBER()` 的 `OVER` 子句会复用该排序：

```sql
WITH selectTemp AS (
  SELECT TOP 100 PERCENT ROW_NUMBER() OVER (order by a desc) as __row_number__, *
  FROM 原始查询 (包含 order by a desc)
)
SELECT * FROM selectTemp
WHERE __row_number__ BETWEEN ? AND ?
ORDER BY __row_number__
```

## Count SQL

```sql
SELECT COUNT(*) FROM (原始查询) as TEMP_T
```

## 标识符引用

使用方括号 `[]`：

```sql
SELECT * FROM [users] WHERE [name] = ?
```

**特别注意**：SQL Server 的默认 schema 为 `dbo`。当仅指定 catalog 不指定 schema 时，自动插入 `dbo`：

```
catalog.[table]  →  [catalog].dbo.[table]
schema.[table]   →  [schema].[table]
```

## 写入冲突策略

| 策略 | SQL 语法 | 主键是否必须 |
|------|---------|:----------:|
| Into | `INSERT INTO ... VALUES (...)` | 否 |
| Ignore | `MERGE INTO ... WHEN NOT MATCHED THEN INSERT ...` | 是 |
| Update | `MERGE INTO ... WHEN MATCHED THEN UPDATE ... WHEN NOT MATCHED THEN INSERT ...` | 是 |

## OUTPUT INSERTED

SQL Server 方言在需要回填主键时生成 `OUTPUT INSERTED`：

```sql
INSERT INTO [dbo].[user_info] ([name], [age])
OUTPUT INSERTED.[id]
VALUES (?, ?), (?, ?), (?, ?)
```

多行插入时通过当前 `ResultSet` 读取（`MultiValuesResultSet`），与 PostgreSQL `RETURNING` 类似。

Ignore/Update + 回填列时保守使用 `OneByOne`（逐条执行）。

## 序列

SQL Server 不实现 `SeqSqlDialect`，通过 `selectKey` 或 `@KeySeq` + `KeyType.Sequence` 读取：

```sql
SELECT NEXT VALUE FOR user_info_id_seq
```

## 注意事项

- `ORDER BY` 中不能出现重复列名
- 分页依赖 `ROW_NUMBER()` + CTE，与 MySQL 的 `LIMIT` 语义不同
- 默认 schema 为 `dbo`，建表时需注意

## 关键差异总结

- 唯一使用方括号 `[]` 引用标识符的数据库
- 唯一使用 `ROW_NUMBER() OVER()` + CTE 实现分页
- 自动插入 `dbo` 作为默认 schema
- `OUTPUT INSERTED` 与 PostgreSQL `RETURNING` 类似，但 Ignore/Update 时不用
