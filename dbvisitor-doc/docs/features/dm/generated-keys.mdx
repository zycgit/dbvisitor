# 自增主键回填

达梦数据库的自增列适合通过 JDBC generated keys 回填。dbVisitor 在达梦方言下不会把有主键回填需求的 INSERT 优化为批量 generated keys，而是保守逐条执行。

## Lambda / BaseMapper

```java title='达梦自增列映射'
@Table("user_info")
public class UserInfo {
    @Column(value = "id", primary = true, keyType = KeyType.Auto)
    private Long id;

    @Column("name")
    private String name;
}
```

```java title='Lambda 新增后读取回填主键'
UserInfo user = new UserInfo();
user.setName("mali");

LambdaTemplate lambda = ...
lambda.insert(UserInfo.class)
      .applyEntity(user)
      .executeSumResult();

Long id = user.getId();
```

## Mapper XML

```xml title='达梦 generated keys'
<insert id="insertUser"
        useGeneratedKeys="true"
        keyProperty="id"
        keyColumn="id">
    INSERT INTO user_info (name)
    VALUES (#{name})
</insert>
```

建议显式写出 `keyColumn`，让回填列和业务主键列保持一致。

## Annotation Mapper

```java
@Insert(
    value = "INSERT INTO user_info (name) VALUES (#{name})",
    useGeneratedKeys = true,
    keyProperty = "id",
    keyColumn = "id"
)
int insertUser(UserInfo user);
```

## Sequence

达梦支持 sequence。达梦官方 FAQ 中给出的方式是使用 `模式名.序列名.NEXTVAL` 获取下一值，`模式名.序列名.CURRVAL` 获取当前值。dbVisitor 的达梦方言会生成：

```sql
SELECT user_info_seq.NEXTVAL
```

Mapper XML 可以使用 `selectKey`：

```xml
<insert id="insertUser">
    <selectKey keyProperty="id" keyColumn="id" order="BEFORE">
        SELECT user_info_seq.NEXTVAL AS id
    </selectKey>
    INSERT INTO user_info (id, name)
    VALUES (#{id}, #{name})
</insert>
```

注解方式：

```java
@SelectKeySql(
    value = "SELECT user_info_seq.NEXTVAL AS id",
    keyProperty = "id",
    keyColumn = "id",
    order = Order.Before
)
@Insert("INSERT INTO user_info (id, name) VALUES (#{id}, #{name})")
int insertUser(UserInfo user);
```

Lambda / BaseMapper 可以使用 `KeyType.Sequence`：

```java
@KeySeq("user_info_seq")
@Column(value = "id", primary = true, keyType = KeyType.Sequence)
private Long id;
```

## 冲突策略

达梦方言的 `Ignore` 策略使用 `IGNORE_ROW_ON_DUPKEY_INDEX` hint，需要有主键列。`Update` 策略使用 `MERGE INTO` 实现：

```sql
MERGE INTO user_info TMP
USING (SELECT ? id, ? name FROM dual) SRC
ON (TMP.id = SRC.id)
WHEN MATCHED THEN UPDATE SET name = SRC.name
WHEN NOT MATCHED THEN INSERT (id, name) VALUES (SRC.id, SRC.name)
```

这些语法主要影响插入冲突处理，不改变 generated keys 的读取模型。

## 方言策略

达梦当前策略如下：

| 场景 | GeneratedKeyStrategy |
| --- | --- |
| 无回填列 | `JdbcBatch` |
| `Into` + 有回填列 | `OneByOne` |
| `Ignore` + 有回填列 | `OneByOne` |
| `Update` + 有回填列 | `OneByOne` |

`DuplicateKeyStrategy.Ignore` 需要主键列；`DuplicateKeyStrategy.Update` 需要主键列且至少有一个非主键列可更新。

## 设计原则

- 自增列：使用 `KeyType.Auto` 或 `useGeneratedKeys=true`。
- sequence：使用 `selectKey` / `@SelectKeySql` / `KeyType.Sequence` 在 INSERT 前取值。
- 有 generated keys 回填时保守逐条执行。
- 通用说明见 [Generated Keys](../../guides/core/mapper/annotation_insert#generated-keys)。
