# H2 自增主键回填

H2 支持常见的 `IDENTITY` 自增列，也支持 sequence。dbVisitor 在 H2 下主要使用 JDBC generated keys 或插入前读取 sequence 两种方式处理主键。

## IDENTITY 列

```sql
CREATE TABLE user_info (
    id   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(64),
    age  INT
)
```

## Lambda / BaseMapper

实体映射中使用 `KeyType.Auto`：

```java title='H2 IDENTITY 映射'
@Table("user_info")
public class UserInfo {
    @Column(value = "id", primary = true, keyType = KeyType.Auto)
    private Long id;

    @Column("name")
    private String name;

    @Column("age")
    private Integer age;
}
```

```java title='Lambda 新增后读取回填主键'
UserInfo user = new UserInfo();
user.setName("mali");
user.setAge(18);

LambdaTemplate lambda = ...
lambda.insert(UserInfo.class)
      .applyEntity(user)
      .executeSumResult();

Long id = user.getId();
```

H2 方言在没有回填列时可以使用普通 JDBC batch；一旦存在 generated key 回填需求，会退回逐条执行，以确保每一行都能稳定回填。

## Mapper XML

```xml title='H2 generated keys'
<insert id="insertUser"
        useGeneratedKeys="true"
        keyProperty="id"
        keyColumn="id">
    INSERT INTO user_info (name, age)
    VALUES (#{name}, #{age})
</insert>
```

## Annotation Mapper

```java
@Insert(
    value = "INSERT INTO user_info (name, age) VALUES (#{name}, #{age})",
    useGeneratedKeys = true,
    keyProperty = "id",
    keyColumn = "id"
)
int insertUser(UserInfo user);
```

## Sequence

H2 方言支持读取 sequence：

```sql
values next value for user_info_seq
```

Mapper XML 可以使用 `selectKey`：

```xml
<insert id="insertUser">
    <selectKey keyProperty="id" keyColumn="id" order="BEFORE">
        values next value for user_info_seq
    </selectKey>
    INSERT INTO user_info (id, name, age)
    VALUES (#{id}, #{name}, #{age})
</insert>
```

Lambda / BaseMapper 可以使用 `KeyType.Sequence`：

```java
@KeySeq("user_info_seq")
@Column(value = "id", primary = true, keyType = KeyType.Sequence)
private Long id;
```

## 方言策略

H2 当前策略如下：

| 场景 | GeneratedKeyStrategy |
| --- | --- |
| 无回填列 | `JdbcBatch` |
| `Into` + 有回填列 | `OneByOne` |
| `Ignore` + 有回填列 | `OneByOne` |
| `Update` + 有回填列 | `OneByOne` |

`DuplicateKeyStrategy.Ignore` / `Update` 由 H2 `MERGE` 实现，需要主键列。

## 设计原则

- `IDENTITY`：使用 `KeyType.Auto` 或 `useGeneratedKeys=true`。
- sequence：使用 `selectKey` / `@SelectKeySql` / `KeyType.Sequence` 在 INSERT 前取值。
- 批量插入无回填时走 JDBC batch；需要回填时保守逐条执行。
- 通用说明见 [Generated Keys](../../guides/core/mapper/annotation_insert#generated-keys)。
