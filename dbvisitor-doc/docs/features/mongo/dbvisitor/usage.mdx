# 数据读写

dbVisitor 将 MongoDB 命令作为可执行语句：`queryForList` 读取结果，`executeUpdate` 读取更新数，`?` 和 `#{...}` 仍用于绑定参数，不需要改写为 SQL。 连接配置见 [JDBC MongoDB](../../../drivers/mongo/connection.mdx).

## 实体映射

```java
@Table(value = "user_info", catalog = "test")
public class UserInfo {
    @Column(primary = true)
    private String uid;
    private String name;
    // 省略 getter 和 setter
}
```

`uid` 是示例业务字段。`primary=true` 不会创建唯一索引；按 uid 更新、删除会影响所有匹配文档。需要使用 MongoDB 的 `_id` 时，见[主键生成](generated-keys.mdx)。

## 执行命令 {#exec-command}

使用对应数据源创建 JdbcTemplate：

```java
JdbcTemplate jdbc = new JdbcTemplate(dataSource);

jdbc.executeUpdate(
        "test.user_info.insertOne({uid: ?, name: ?})",
        new Object[] { "1001", "mali" });

List<UserInfo> rows = jdbc.queryForList(
        "test.user_info.find({uid: ?})",
        new Object[] { "1001" }, UserInfo.class);

jdbc.executeUpdate(
        "test.user_info.updateMany({uid: ?}, {$set: {name: ?}})",
        new Object[] { "1001", "new name" });

jdbc.executeUpdate(
        "test.user_info.deleteMany({uid: ?})",
        new Object[] { "1001" });
```

## 复杂条件使用命令

需要组合条件时，直接绑定 MongoDB 条件：

```java
List<Map<String, Object>> rows = jdbc.queryForList(
        "test.user_info.find({$or: [{name: ?}, {uid: ?}]})",
        new Object[] { "mali", "1001" });
```

## 构造器聚合与投影

`applySelect` 使用 MongoDB 表达式，不使用 SQL 的 `SUM(age)` 等写法。结合 `groupBy` 时，传入累加器文档：

```java
List<Map<String, Object>> groups = lambda.query(UserInfo.class)
        .applySelect("{cnt: {$sum: 1}}")
        .groupBy("age")
        .orderBy("age")
        .queryForMapList();
```

此操作按 `age` 分组，返回 `age`、`cnt` 两列。驱动生成 `$group`，将分组字段展开为结果列。

不调用 `groupBy` 时，表达式文档用于 `$project`；数组用于完整聚合管线：

```java
Long total = lambda.query(UserInfo.class)
        .applySelect("[{$group: {_id: null, value: {$sum: '$age'}}}, {$project: {_id: 0, value: 1}}]")
        .eq("name", name)
        .queryForObject(Long.class);
```

条件通过参数绑定生成前置 `$match`；`orderBy` 生成末尾 `$sort`。管线数组不能再与 `groupBy` 或普通字段投影组合。

:::caution
`applySelect` 的内容是命令表达式，只使用程序中确定的表达式。用户输入应通过 `eq` 等条件参数传入，不要拼接到表达式中。
:::

更多原生命令见[命令语法](../about.md)。

## 插入冲突

```java
lambda.insert(UserInfo.class)
        .onDuplicateStrategy(DuplicateKeyStrategy.Update)
        .applyEntity(user)
        .executeSumResult();
```

`Ignore` 按映射主键查找，存在时保留原文档，不存在时插入；`Update` 存在时修改本次提供的非主键字段，不存在时插入。操作使用 MongoDB 原生 upsert，不会先查询再写入。

必须提供全部映射主键，并为这些字段建立唯一索引；`primary=true` 不会代建索引。其他唯一字段的冲突仍会报错。只有实际新增的文档返回生成键。

:::note 更新条数
更新返回实际改变的文档数。例如匹配 3 条文档，其中 1 条的值已经相同，返回 `2`，不是 `3`。upsert 新增一条文档返回 `1`。
:::

返回列的读取见[结果读取](results.mdx)。多条命令不等于 JDBC batch，也不会自动构成事务。
