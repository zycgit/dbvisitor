# 数据读写

dbVisitor 将 MongoDB 命令作为可执行语句：`queryForList` 读取结果，`executeUpdate` 读取更新数，`?` 和 `#{...}` 仍用于绑定参数，不需要改写为 SQL。 连接配置见 [JDBC MongoDB](../../../drivers/mongo/connection.mdx).

## 实体映射

```java
@Table(value = "user_info", catalog = "test")
public class UserInfo {
    @Column(primary = true)
    private String uid;
    private String name;
    // 省略 getter 和 setter
}
```

`uid` 是示例业务字段。`primary=true` 不会创建唯一索引；按 uid 更新、删除会影响所有匹配文档。需要使用 MongoDB 的 `_id` 时，见[主键生成](generated-keys.mdx)。

## 执行命令 {#exec-command}

使用对应数据源创建 JdbcTemplate：

```java
JdbcTemplate jdbc = new JdbcTemplate(dataSource);

jdbc.executeUpdate(
        "test.user_info.insertOne({uid: ?, name: ?})",
        new Object[] { "1001", "mali" });

List<UserInfo> rows = jdbc.queryForList(
        "test.user_info.find({uid: ?})",
        new Object[] { "1001" }, UserInfo.class);

jdbc.executeUpdate(
        "test.user_info.updateMany({uid: ?}, {$set: {name: ?}})",
        new Object[] { "1001", "new name" });

jdbc.executeUpdate(
        "test.user_info.deleteMany({uid: ?})",
        new Object[] { "1001" });
```

## 不同 API 如何查询

<Tabs>
<TabItem value="fluent" label="构造器 API" default>

```java
LambdaTemplate lambda = new LambdaTemplate(dataSource);
UserInfo item = lambda.query(UserInfo.class)
        .eq(UserInfo::getUid, "1001")
        .queryForObject();
```

构造器操作对应以下数据库动作：

| 操作 | 数据库动作 |
| --- | --- |
| 查询 | find |
| 修改指定属性 | updateMany + $set |
| 删除匹配记录 | deleteMany |

BaseMapper 的 CRUD 复用相同操作。

</TabItem>
<TabItem value="annotation" label="方法注解">

```java
@SimpleMapper
public interface UserInfoMapper {
    @Query("test.user_info.find({uid: #{uid}})")
    UserInfo findById(@Param("uid") String uid);
}
```

```java
Session session = new Configuration().newSession(dataSource);
UserInfoMapper mapper = session.createMapper(UserInfoMapper.class);
UserInfo item = mapper.findById("1001");
```

<TabItem value="xml" label="Mapper 文件">

```xml
<mapper namespace="com.example.UserInfoMapper">
    <select id="findById" resultType="com.example.UserInfo">

    </select>

```

```java
@RefMapper("/mapper/mongo-user.xml")
public interface UserInfoMapper {
    UserInfo findById(@Param("uid") String uid);
}
```

XML 保存到 @RefMapper 指定的资源路径；示例类位于 com.example 包。通过 Session 创建 Mapper，方式与方法注解相同。

## 复杂条件使用命令

需要组合条件时，直接绑定 MongoDB 条件：

```java
List<Map<String, Object>> rows = jdbc.queryForList(
        "test.user_info.find({$or: [{name: ?}, {uid: ?}]})",
        new Object[] { "mali", "1001" });
```

构造器不能替代任意 BSON 条件组合；嵌套 AND/OR、聚合和自定义投影使用[命令语法](../about.md)。

返回列的读取见[结果读取](results.mdx)。多条命令不等于 JDBC batch，也不会自动构成事务。
