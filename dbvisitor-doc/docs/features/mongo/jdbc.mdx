先完成[独立 JDBC 驱动的安装与连接](../../drivers/mongo/connection.mdx)。本页直接使用 JDBC，不要求使用 dbVisitor 上层 API。除示例自行创建连接外，`conn` 表示应用已打开并负责关闭的 JDBC 连接。

## 常用操作示例

### 1) 创建集合（DDL）
```java
try (Statement stmt = conn.createStatement()) {
    stmt.execute("use mydb");
    stmt.executeUpdate("db.createCollection('capped_col', { capped: true, size: 1024, max: 100 })");
}
```

### 2) 插入与更新（DML）
```java
try (Statement stmt = conn.createStatement()) {
    stmt.executeUpdate("db.mycol.insert({name:'zhangsan'})");
    stmt.executeUpdate("db.mycol.update({name:'zhangsan'}, {$set:{age:20}})");
}
```

这里的 `db.mycol` 使用当前数据库；指定其他库时可写成 `mydb1.mycol.insert(...)`，后续查询或更新也应使用相同的数据库。

### 3) 使用 `ObjectId(?)` 查询（DQL）
```java
try (PreparedStatement ps = conn.prepareStatement("db.complex_order.find({_id: ObjectId(?)})")) {
    ps.setString(1, "69399ba1c488515851cecdfb");
    try (ResultSet rs = ps.executeQuery()) {
        while (rs.next()) {
            rs.getString("_JSON");
        }
    }
}
```

### 4) 带参数的聚合
```java
try (PreparedStatement ps = conn.prepareStatement(
        "db.mycol.aggregate([{$match: {}}], { allowDiskUse: ?, batchSize: ? })")) {
    ps.setBoolean(1, true);
    ps.setInt(2, 100);
    ps.executeQuery();
}
```

## 多命令与 JDBC 结果

```java
try (Statement stmt = conn.createStatement()) {
    boolean hasResult = stmt.execute("db.mycol.find({}).limit(2); db.mycol.count({})");
    while (true) {
        if (hasResult) {
            try (ResultSet rs = stmt.getResultSet()) {
                while (rs.next()) {
                    System.out.println(rs.getObject(1));
                }
            }
        } else {
            long count = stmt.getLargeUpdateCount();
            if (count == -1) {
                break;
            }
            System.out.println("updated=" + count);
        }
        hasResult = stmt.getMoreResults(Statement.CLOSE_CURRENT_RESULT);
    }
}
```

查询使用 executeQuery；写入使用 executeUpdate 或 execute。多个命令以分号分隔，通过 execute/getMoreResults 读取，不等于 JDBC batch，也不构成事务。Hint 必须放在命令开头；完整 Hint 与限制见[命令参考](./commands.md)。

## 预读与结果列 {#pre-read}

`preRead=true` 默认预读结果并展开文档字段，同时保留 `_ID`/`_JSON`。关闭时按专用列读取原始文档；不要继续假设存在展开字段。preReadThreshold/preReadMaxFileSize 支持 B/KB/MB/GB；无单位按 MB，缓存目录默认 java.io.tmpdir。预读可能增加内存、磁盘和首行等待成本，并不是服务端分页上限。
