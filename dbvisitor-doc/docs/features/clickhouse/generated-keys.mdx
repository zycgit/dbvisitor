# 主键生成

在插入前生成业务 ID，写入后直接从实体读取。下面以 `KeyType.UUID32` 为例。

:::info[说明]
通用配置见[主键生成与回填](../../guides/core/mapper/annotation_insert#generated-keys)。
:::

## 使用应用侧 ID

```sql
CREATE TABLE event_log (id String, event_name String)
ENGINE = MergeTree ORDER BY id;
```

如果业务需要唯一 ID，建议在 Java 侧生成，例如 UUID、雪花 ID 或业务号。

<Tabs>
<TabItem value="application-lambda" label="构造器 API" default>

```java title='ClickHouse 应用侧 ID 映射'
@Table("event_log")
public class EventLog {
    @Column(value = "id", primary = true, keyType = KeyType.UUID32)
    private String id;

    @Column("event_name")
    private String eventName;
}
```

```java title='Lambda 插入'
EventLog event = new EventLog();
event.setEventName("login");

LambdaTemplate lambda = ...;
lambda.insert(EventLog.class)
      .applyEntity(event)
      .executeSumResult();

String id = event.getId();
```

`KeyType.UUID32` / `KeyType.UUID36` 属于插入前生成，不依赖 ClickHouse 返回 generated keys。

</TabItem>
<TabItem value="application-annotation" label="方法注解">

```java
@Insert("INSERT INTO event_log (id, event_name) VALUES (#{id}, #{eventName})")
int insertEvent(EventLog event);
```


调用 Mapper 前先生成 ID：

```java
import java.util.UUID;

EventLog event = new EventLog();
event.setId(UUID.randomUUID().toString().replace("-", ""));
event.setEventName("login");
mapper.insertEvent(event);
```

</TabItem>
<TabItem value="application-xml" label="Mapper 文件">

Mapper SQL 应明确写入应用侧生成的 ID：

```xml title='推荐'
<insert id="insertEvent">
    INSERT INTO event_log (id, event_name)
    VALUES (#{id}, #{eventName})
</insert>
```

</TabItem>
</Tabs>
