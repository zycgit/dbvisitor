# 主键生成

MySQL 使用 `AUTO_INCREMENT` 生成主键，插入后可将值自动写回实体。

:::info[说明]
通用配置见[主键生成与回填](../../guides/core/mapper/annotation_insert#generated-keys)。
:::

## 使用 AUTO_INCREMENT

```sql
CREATE TABLE user_info (
    id INTEGER PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(64)
) ENGINE=InnoDB;
```

<Tabs>
<TabItem value="identity-lambda" label="构造器 API" default>

```java
@Table("user_info")
public class UserInfo {
    @Column(value = "id", primary = true, keyType = KeyType.Auto)
    private Integer id;
    @Column("name")
    private String name;
}
```

```java
UserInfo user = new UserInfo();
user.setName("mali");

LambdaTemplate lambda = ...;
lambda.insert(UserInfo.class).applyEntity(user).executeSumResult();

Integer id = user.getId(); // 自动回填
```



</TabItem>
<TabItem value="identity-annotation" label="方法注解">

```java title='方法注解'
@Insert(value = "INSERT INTO user_info (name) VALUES (#{name})",
        useGeneratedKeys = true, keyProperty = "id", keyColumn = "id")
int insertUser(UserInfo user);
```

</TabItem>
<TabItem value="identity-xml" label="Mapper 文件">

```xml title='Mapper 文件'
<insert id="insertUser" useGeneratedKeys="true" keyProperty="id" keyColumn="id">
    INSERT INTO user_info (name) VALUES (#{name})
</insert>
```

</TabItem>
</Tabs>

:::caution[注意]
插入多个实体后，从各实体属性读取 ID，不要从第一个 ID 推算其它主键。插入冲突导致跳过或更新已有记录时，不保证回填主键。
:::
