# MySQL 方言细节

## 分页 SQL

MySQL 方言使用 `LIMIT` / `OFFSET` 语法，offset 为 0 时省略 `OFFSET`：

```sql
-- offset=1, limit=3
SELECT ... LIMIT ?, ?

-- offset=0, limit=3（省略 OFFSET）
SELECT ... LIMIT ?
```

参数顺序：`LIMIT offset, limit`（注意：MySQL 的 LIMIT 语法是 `LIMIT offset, count`，不是 `LIMIT count OFFSET offset`）。

## Count SQL

```sql
SELECT COUNT(*) FROM (原始查询) as TEMP_T
```

## 标识符引用

使用反引号 `` ` ``：

```sql
SELECT * FROM `users` WHERE `name` = ?
```

多级引用自动添加 schema 前缀：`\`db\`.\`users\``

## LIKE 语法

| LIKE 类型 | 生成的 SQL |
|-----------|-----------|
| 全模糊 | `LIKE CONCAT('%', ?, '%')` |
| 左模糊 | `LIKE CONCAT('%', ?)` |
| 右模糊 | `LIKE CONCAT(?, '%')` |

## 写入冲突策略

| 策略 | SQL 语法 | 主键是否必须 |
|------|---------|:----------:|
| Into | `INSERT INTO ... VALUES (...)` | 否 |
| Ignore | `INSERT IGNORE INTO ... VALUES (...)` | 否 |
| Update | `INSERT INTO ... ON DUPLICATE KEY UPDATE col=VALUES(col), ...` | 否 |

MySQL 不强制要求配置主键列即可使用 Ignore/Update 策略。冲突检测基于表的唯一键约束。

## 空值排序

支持 `ORDER BY ... NULLS FIRST` / `NULLS LAST`。

## 关键差异总结

- 唯一使用反引号的数据库
- 是唯一不要求主键即可使用 Ignore/Update 的数据库
- `LIMIT offset, count` 语义（offset 在前，count 在后）
- 不支持序列
- 不支持向量搜索
- 支持存储过程
