# DB2 自增主键回填

DB2 支持 identity 列和 sequence。对于 identity 列，可以使用 JDBC generated keys；对于 sequence，更推荐在 INSERT 前取值。

IBM 文档说明 DB2 JDBC 支持读取自动生成键，但 batch generated keys 存在限制，某些配置下不能把准备返回 generated keys 的 `PreparedStatement` 用于 batch updates。参考 [IBM DB2 generated keys 文档](https://www.ibm.com/docs/en/db2-for-zos/12.0.0?topic=sql-retrieval-automatically-generated-keys-in-jdbc-applications)。

dbVisitor 因此在 DB2 下采用保守策略：无回填列时使用普通 JDBC batch；有回填列时逐条执行，避免批量回填顺序和驱动限制带来的不确定性。

## IDENTITY 列

```sql
CREATE TABLE user_info (
    id   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(64),
    age  INT
)
```

## Lambda / BaseMapper

```java title='DB2 IDENTITY 映射'
@Table("user_info")
public class UserInfo {
    @Column(value = "id", primary = true, keyType = KeyType.Auto)
    private Long id;

    @Column("name")
    private String name;
}
```

```java title='Lambda 新增后读取回填主键'
UserInfo user = new UserInfo();
user.setName("mali");

LambdaTemplate lambda = ...
lambda.insert(UserInfo.class)
      .applyEntity(user)
      .executeSumResult();

Long id = user.getId();
```

## Mapper XML

```xml title='DB2 generated keys'
<insert id="insertUser"
        useGeneratedKeys="true"
        keyProperty="id"
        keyColumn="id">
    INSERT INTO user_info (name)
    VALUES (#{name})
</insert>
```

## Annotation Mapper

```java
@Insert(
    value = "INSERT INTO user_info (name) VALUES (#{name})",
    useGeneratedKeys = true,
    keyProperty = "id",
    keyColumn = "id"
)
int insertUser(UserInfo user);
```

## Sequence

DB2 方言支持读取 sequence：

```sql
VALUES NEXT VALUE FOR user_info_seq
```

Mapper XML：

```xml
<insert id="insertUser">
    <selectKey keyProperty="id" keyColumn="id" order="BEFORE">
        VALUES NEXT VALUE FOR user_info_seq
    </selectKey>
    INSERT INTO user_info (id, name)
    VALUES (#{id}, #{name})
</insert>
```

Lambda / BaseMapper：

```java
@KeySeq("user_info_seq")
@Column(value = "id", primary = true, keyType = KeyType.Sequence)
private Long id;
```

## 方言策略

DB2 当前策略如下：

| 场景 | GeneratedKeyStrategy |
| --- | --- |
| 无回填列 | `JdbcBatch` |
| `Into` + 有回填列 | `OneByOne` |
| `Ignore` + 有回填列 | `OneByOne` |
| `Update` + 有回填列 | `OneByOne` |

`DuplicateKeyStrategy.Ignore` / `Update` 由 DB2 `MERGE` 实现，需要主键列。

## 设计原则

- identity：使用 `KeyType.Auto` 或 `useGeneratedKeys=true`。
- sequence：使用 `selectKey` / `@SelectKeySql` / `KeyType.Sequence` 在 INSERT 前取值。
- DB2 有 generated keys 回填时保守逐条执行；无回填时可使用普通 JDBC batch。
- 通用说明见 [Generated Keys](../../guides/core/mapper/annotation_insert#generated-keys)。
