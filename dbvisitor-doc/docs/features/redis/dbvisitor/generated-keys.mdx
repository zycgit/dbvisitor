# 键与编号

Redis 的键由应用指定，不会通过 generated keys 回填实体属性。例如，编号 1001 的用户可以保存到 user:1001。

需要递增编号时，先读取 INCR 的结果，再组成键名：

```java
Long id = jdbc.queryForLong("INCR ?", "user:sequence");
String key = "user:" + id;
jdbc.executeUpdate("HSET ? ? ?", new Object[] { key, "name", "mali" });
```

INCR 和 HSET 是两条独立命令。写入失败不会归还编号；业务需要重试时，可以保留已取得的 id 再写入。
