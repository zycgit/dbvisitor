# 主键生成

PostgreSQL 常用 `SERIAL`、`BIGSERIAL`、`IDENTITY` 或 sequence 生成主键。前三者由数据库在 INSERT 时生成，dbVisitor 在写入后把主键值写回实体；sequence 也可以在 INSERT 前取值。

:::info[说明]
通用配置见[主键生成与回填](../../guides/core/mapper/annotation_insert#generated-keys)。
:::

## 使用 SERIAL / IDENTITY

```sql
CREATE TABLE user_info (
    id   BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(64),
    age  INTEGER
)
```

实体主键使用 `KeyType.Auto`：

```java
@Table("user_info")
public class UserInfo {
    @Column(value = "id", primary = true, keyType = KeyType.Auto)
    private Long id;

    private String name;
    private Integer age;
}
```

<Tabs>
<TabItem value="identity-lambda" label="构造器 API" default>

构造器 API 根据实体映射生成 INSERT，并把 PostgreSQL 返回的主键写回当前实体。

```java title='新增后属性自动回填'
UserInfo user = new UserInfo();
user.setName("mali");
user.setAge(18);

LambdaTemplate lambda = ...;
int rows = lambda.insert(UserInfo.class)
                 .applyEntity(user)
                 .executeSumResult();

Long id = user.getId();
```

</TabItem>
<TabItem value="identity-annotation" label="方法注解">

```java
@Insert(
    value = "INSERT INTO user_info (name, age) VALUES (#{name}, #{age})",
    useGeneratedKeys = true,
    keyProperty = "id",
    keyColumn = "id"
)
int insertUser(UserInfo user);
```

显式使用 `RETURNING` 或返回普通字段的方式见[数据回填](./backfill.mdx)。

</TabItem>
<TabItem value="identity-xml" label="Mapper 文件">

只回填数据库生成的主键时，可以使用 JDBC generated keys：

```xml
<insert id="insertUser"
        useGeneratedKeys="true"
        keyProperty="id"
        keyColumn="id">
    INSERT INTO user_info (name, age)
    VALUES (#{name}, #{age})
</insert>
```

</TabItem>
</Tabs>

:::caution[注意]
Ignore 跳过的记录不会返回主键；处理已有记录的用法见[插入冲突](./conflict.mdx)。
:::

## 使用序列

下面使用普通主键列和序列，与上面的自增列示例独立：

```sql
CREATE TABLE user_info (
    id BIGINT PRIMARY KEY,
    name VARCHAR(64),
    age INTEGER
);
CREATE SEQUENCE user_info_id_seq START WITH 1 INCREMENT BY 1;
```

<Tabs>
<TabItem value="sequence-lambda" label="构造器 API" default>

```java
import net.hasor.dbvisitor.mapping.Column;
import net.hasor.dbvisitor.mapping.KeySeq;
import net.hasor.dbvisitor.mapping.KeyType;
import net.hasor.dbvisitor.mapping.Table;

@Table("user_info")
public class UserInfo {
    @Column(primary = true, keyType = KeyType.Sequence)
    @KeySeq("user_info_id_seq")
    private Long id;
    private String name;
    private Integer age;

    // 省略 getter 和 setter
}
```

```java
UserInfo user = new UserInfo();
user.setName("mali");

lambda.insert(UserInfo.class)
        .applyEntity(user)
        .executeSumResult();

Long id = user.getId();
```

每次插入前自动获取序列值，赋给 `id` 后再写入记录。

</TabItem>
<TabItem value="sequence-annotation" label="方法注解">

```java
@SelectKeySql(
    value = "SELECT nextval('user_info_id_seq')",
    keyProperty = "id",
    keyColumn = "id",
    order = Order.Before
)
@Insert("INSERT INTO user_info (id, name, age) VALUES (#{id}, #{name}, #{age})")
int insertUser(UserInfo user);
```

</TabItem>
<TabItem value="sequence-xml" label="Mapper 文件">

```xml
<insert id="insertUser">
    <selectKey keyProperty="id" order="BEFORE">
        SELECT nextval('user_info_id_seq')
    </selectKey>
    INSERT INTO user_info (id, name, age)
    VALUES (#{id}, #{name}, #{age})
</insert>
```

</TabItem>
