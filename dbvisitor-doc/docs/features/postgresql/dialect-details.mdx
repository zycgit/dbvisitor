# 方言细节

## 分页 SQL

PostgreSQL 方言使用 `LIMIT ? OFFSET ?` 语法：

```sql
-- offset=1, limit=3
SELECT ... LIMIT ? OFFSET ?
```

参数顺序：`LIMIT count OFFSET offset`。

## Count SQL

```sql
SELECT COUNT(*) FROM (原始查询) as TEMP_T
```

## 标识符引用

使用双引号 `"`：

```sql
SELECT * FROM "users" WHERE "name" = ?
```

## LIKE 语法

| LIKE 类型 | 生成的 SQL |
|-----------|-----------|
| 全模糊 | `LIKE '%' || ? || '%'` |
| 左模糊 | `LIKE '%' || ?` |
| 右模糊 | `LIKE ? || '%'` |

使用 `||` 字符串连接（而非 MySQL 的 `CONCAT`）。

## 写入冲突策略

| 策略 | SQL 语法 | 主键是否必须 |
|------|---------|:----------:|
| Into | `INSERT INTO ... VALUES (...)` | 否 |
| Ignore | `INSERT INTO ... ON CONFLICT DO NOTHING` | 否 |
| Update | `INSERT INTO ... ON CONFLICT("pk") DO UPDATE SET ("col1","col2") = (EXCLUDED."col1", EXCLUDED."col2")` | 是 |

**Update 策略的特殊限制**：至少需要一个非主键列可更新。如果表只有主键列（无其他列），Update 策略不可用（会返回 `false`）。

## 序列

PostgreSQL 方言实现了 `SeqSqlDialect`，支持 `nextval()`：

```sql
SELECT NEXTVAL('user_info_id_seq')
```

对象映射中通过 `@KeySeq("user_info_id_seq")` + `KeyType.Sequence` 使用。

## RETURNING 子句

PostgreSQL 原生支持 `INSERT ... RETURNING <column>`。Lambda/BaseMapper 在多行插入 + 主键回填时生成：

```sql
INSERT INTO "user_info" ("name", "age")
VALUES (?, ?), (?, ?), (?, ?)
RETURNING "id"
```

配合 `ON CONFLICT DO UPDATE` 也可追加 `RETURNING`：

```sql
INSERT INTO "user_info" ("id", "name", "age") VALUES (?, ?, ?), (?, ?, ?)
ON CONFLICT ("id") DO UPDATE SET ("name", "age") = (EXCLUDED."name", EXCLUDED."age")
RETURNING "id"
```

生成的键列通过当前 `ResultSet` 读取（`MultiValuesResultSet`）。

## 向量搜索

PostgreSQL 通过 pgvector 扩展支持向量搜索，实现了 `VectorSqlDialect`：

| 度量方式 | 运算符 |
|---------|-------|
| L2 欧氏距离 | `<->` |
| 余弦距离 | `<=>` |
| 内积 | `<#>` |

## 关键差异总结

- `RETURNING` 返回多行主键（`MultiValuesResultSet`），是唯一在 Update 冲突策略下也能使用 `RETURNING` 的数据库
- `ON CONFLICT DO NOTHING` 不要求主键列
- `ON CONFLICT DO UPDATE` 要求主键列且至少一个非主键列
- 字符串连接用 `||`，而非 `CONCAT`
- 支持序列 + 向量搜索
