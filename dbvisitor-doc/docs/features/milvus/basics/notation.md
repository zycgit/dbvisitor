## 语法约定

语法模板放在 `text` 代码块中，大写单词表示关键字，小写名称表示需要替换的对象或值。`[ ... ]` 表示可选部分，`{ A | B }` 表示二选一，`...` 表示按所示分隔符重复前一项。这些模板记号本身不是 SQL。

`sql` 代码块是语法示例；执行前需要准备相应集合、字段、索引和数据，并绑定其中的 `?`。SQL 向量值 `[0.1, 0.2]` 的方括号是真实语法，不是可选记号。


## 注释与多语句

`--` 开始行注释。`/*+ ... */` 是命令前的 Hint，不是普通注释，应放在其作用的语句之前。

同一次执行可用分号分隔多条语句，参数连续编号。使用 `execute()` 和 `getMoreResults()` 按顺序读取结果，详见 [JDBC 结果与返回列](../../../drivers/milvus/results.md)。多语句不是 JDBC batch，也不提供事务；执行失败时，前面已生效的操作不会因此回滚。
