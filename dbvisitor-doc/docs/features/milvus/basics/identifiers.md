## 标识符与作用域

SQL 关键字不区分大小写；名称是否区分大小写由 Milvus 决定。数据库、集合、字段和索引使用普通标识符，建议以字母或下划线开头，后续只使用字母、数字和下划线，并避开关键字。名称最终由服务端校验。

不支持双引号或反引号包围的标识符。词法允许点号或连字符出现在名称中，但不会把 `database.collection` 解释为跨库引用。默认作用域是连接数据库；只有明确提供 `IN DATABASE` 或 `ON DATABASE` 的命令才接受显式数据库范围。

名称、类型和约束关键字不能通过 `?` 绑定。需要动态选择集合或字段时，应从应用的可信名称白名单中选择，不能直接拼接用户输入。
