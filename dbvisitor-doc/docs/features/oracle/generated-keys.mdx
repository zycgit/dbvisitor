# 主键生成

Oracle 支持 `IDENTITY` 列，也长期使用 sequence 生成主键。两种方式在 dbVisitor 中的推荐配置不同：

- `IDENTITY`：插入后由数据库生成，使用 JDBC generated keys 回填。
- sequence：插入前先取序列值，再把主键值带入 INSERT。

:::info[说明]
通用配置见[主键生成与回填](../../guides/core/mapper/annotation_insert#generated-keys)。
:::

## 使用 IDENTITY

Oracle 12c+ 可以使用 `IDENTITY` 列：

```sql
CREATE TABLE user_info (
    id   NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR2(64),
    age  NUMBER
)
```

<Tabs>
<TabItem value="identity-lambda" label="构造器 API" default>

主键属性配置 `KeyType.Auto`，插入后自动回填。

```java title='Oracle IDENTITY 映射'
@Table("user_info")
public class UserInfo {
    @Column(value = "id", primary = true, keyType = KeyType.Auto)
    private Integer id;

    @Column("name")
    private String name;

    @Column("age")
    private Integer age;
}
```

```java title='新增后属性自动回填'
UserInfo user = new UserInfo();
user.setName("mali");
user.setAge(18);

LambdaTemplate lambda = ...;
int rows = lambda.insert(UserInfo.class)
                 .applyEntity(user)
                 .executeSumResult();

Integer id = user.getId();
```

:::caution[注意]

- 多个对象逐条插入、分别回填主键，不使用 JDBC 批处理。
- 发生[插入冲突](./conflict.mdx)时，跳过插入或更新已有记录不保证回填主键。

:::

</TabItem>
<TabItem value="identity-annotation" label="方法注解">

设置 `useGeneratedKeys = true`，用 `keyProperty` 指定回填属性、`keyColumn` 指定主键列：

```java
@Insert(
    value = "INSERT INTO user_info (name, age) VALUES (#{name}, #{age})",
    useGeneratedKeys = true,
    keyProperty = "id",
    keyColumn = "id"
)
int insertUser(UserInfo user);
```

</TabItem>
<TabItem value="identity-xml" label="Mapper 文件">

设置 `useGeneratedKeys="true"`，用 `keyProperty` 指定回填属性、`keyColumn` 指定主键列：

```xml title='Oracle IDENTITY generated keys'
<insert id="insertUser"
        useGeneratedKeys="true"
        keyProperty="id"
        keyColumn="id">
    INSERT INTO user_info (name, age)
    VALUES (#{name}, #{age})
</insert>
```

</TabItem>
</Tabs>

## 使用序列

下面使用普通主键列和序列，与上面的 IDENTITY 示例独立：

```sql
CREATE TABLE user_info (
    id NUMBER(10) PRIMARY KEY,
    name VARCHAR2(100),
    age NUMBER(3)
);
CREATE SEQUENCE user_info_seq START WITH 1 INCREMENT BY 1;
```

<Tabs>
<TabItem value="sequence-lambda" label="构造器 API" default>

主键属性配置 `KeyType.Sequence`，通过 `@KeySeq` 指定序列：

```java
import net.hasor.dbvisitor.mapping.Column;
import net.hasor.dbvisitor.mapping.KeySeq;
import net.hasor.dbvisitor.mapping.KeyType;
import net.hasor.dbvisitor.mapping.Table;

@Table("user_info")
public class UserInfo {
    @Column(primary = true, keyType = KeyType.Sequence)
    @KeySeq("user_info_seq")
    private Integer id;
    private String name;
    private Integer age;

    // 省略 getter 和 setter
}
```

```java
UserInfo user = new UserInfo();
user.setName("mali");

lambda.insert(UserInfo.class)
      .applyEntity(user)
      .executeSumResult();
```

插入前自动执行 `SELECT user_info_seq.NEXTVAL FROM dual`，将值写入 `user.id`，再插入记录。传入多个实体时，每个实体分别获取序列值。

</TabItem>
<TabItem value="sequence-annotation" label="方法注解">

注解方式可以使用 `@SelectKeySql`：

```java
@SelectKeySql(
    value = "SELECT user_info_seq.NEXTVAL AS id FROM dual",
    keyProperty = "id",
    keyColumn = "id",
    order = Order.Before
)
@Insert("INSERT INTO user_info (id, name, age) VALUES (#{id}, #{name}, #{age})")
int insertUser(UserInfo user);
```

</TabItem>
<TabItem value="sequence-xml" label="Mapper 文件">

```xml title='Mapper 文件使用 selectKey'
<insert id="insertUser">
    <selectKey keyProperty="id" keyColumn="id" order="BEFORE">
        SELECT user_info_seq.NEXTVAL AS id FROM dual
    </selectKey>
    INSERT INTO user_info (id, name, age)
    VALUES (#{id}, #{name}, #{age})
</insert>
```

</TabItem>
