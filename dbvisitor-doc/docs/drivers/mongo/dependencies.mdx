<span id="依赖与版本" />

运行环境要求 Java 17 或更高版本。Maven 和 Gradle 任选一种。

## Maven

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>jdbc-mongo</artifactId>
    <version>@project.docsVersion@</version>
    <classifier>all</classifier>
</dependency>
```

## Gradle

```groovy
repositories { mavenCentral() }
dependencies { implementation "net.hasor:jdbc-mongo:@project.docsVersion@:all" }
```


引入依赖后，[建立数据库连接](./connection.mdx)。
