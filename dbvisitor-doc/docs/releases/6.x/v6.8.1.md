# v6.8.1（开发中）

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>dbvisitor</artifactId>
    <version>6.8.1</version>
</dependency>
```

## 更新内容

- Milvus JDBC 支持不带 `FROM` 的单值 `SELECT`，兼容 DataGrip 的 `SELECT 'keep alive'`，常量查询在本地执行。新增 `PING` 命令用于服务端连接探测，成功返回 `PONG`，失败抛出异常。
- 修复注解 `@Query` 返回 `PageResult<T>` 时被误判为单行结果的问题，正确返回分页数据和总数，空页也保留分页结果对象。
- 修复 `jdbc-milvus`、`jdbc-mongo`、`jdbc-redis`、`jdbc-elastic` 仅发布 `all` 分类制品、缺少默认 JAR 的问题。驱动主制品包含重定位后的 ANTLR 运行时，数据库 SDK 仍通过传递依赖引入。

## 升级说明

- 从 6.8.0 升级以上四个 JDBC 驱动到 6.8.1 时，删除 Maven 依赖中的 `<classifier>all</classifier>`；Gradle 依赖也删除版本号后的 `:all`。6.8.0 的既有制品仍需保留该分类。
- JDBC URL、驱动类名和调用方式不变。DataGrip 等手动管理依赖的工具需替换旧驱动 JAR，并保留所需的运行时依赖。
