# v6.8.1 (2026-09-18)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>dbvisitor</artifactId>
    <version>6.8.1</version>
</dependency>
```

## 更新内容

- 新增
  - Milvus JDBC 支持不带 `FROM` 的单值 `SELECT`，在本地执行 DataGrip 的 `SELECT 'keep alive'` 等常量查询。
  - Milvus JDBC 新增 `PING` 命令探测服务端连接，成功返回 `PONG`，失败抛出异常。
  - `jdbc-milvus`、`jdbc-mongo`、`jdbc-redis`、`jdbc-elastic` 新增包含运行依赖的 `alone` 包，便于 SQL Client 加载。
- 修复
  - 修复 `@Query` 返回 `PageResult<T>` 时被误判为单行结果的问题。
  - 修复上述四个 JDBC 驱动仅发布 `all` 分类制品、缺少默认 JAR 的问题。
- 优化
  - 四个 JDBC 驱动的默认 JAR 内置并重定位 ANTLR 运行时，减少依赖冲突。

## 升级说明

- Maven 使用四个 JDBC 驱动的 6.8.1 默认包时，删除 `<classifier>all</classifier>`。
- Gradle 使用四个 JDBC 驱动的 6.8.1 默认包时，删除版本号后的 `:all`。
- 继续使用 6.8.0 驱动制品时，仍需保留 `all` 分类。
- JDBC URL、驱动类名和调用方式保持兼容。
- DataGrip、DBeaver 等 SQL Client 可使用对应的 `alone` 包替换旧驱动及其配套依赖 JAR。
