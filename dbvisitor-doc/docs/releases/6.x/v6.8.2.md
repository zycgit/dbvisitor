# v6.8.2（开发中）

## 更新内容

- 新增
  - Hasor 整合的 `SessionConfigurer` 新增 `SessionConfigurer(String sourceName)` 和 `getSourceName()`，简化命名数据源的配置。
  - 文档站新增中英文 `llms.txt`，为 AI 提供项目介绍与文档索引。
- 修复
  - 修复英文文档中数据源及驱动章节的侧栏菜单翻译缺失。
- 优化
  - Cobble 升级至 `5.0.4`。
  - 补充 One Access 理念、双层适配器架构，以及 `JdbcTemplate`、`LambdaTemplate` 和 Mapper 的 SQL/DSL 适用范围。
  - 将 IDE 代码格式配置统一移至 `community` 目录。
