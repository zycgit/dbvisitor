# 最新版本

最新正式版本：**v{Vars.lastReleaseVer}**<br/>
发布日期：**{Vars.lastReleaseTime}**<br/>
当前使用指南对应开发版：**{Vars.docsVersion}**。正式版与开发版的能力可能不同，请结合对应版本说明阅读。<br/>
版本定义：**主版本号.次版本号.修订版本**<br/>

- **主版本**
  - 架构发生重大变化
  - 产品目标发生变化
  - API 发生重大变化
- **次版本**
  - 新增组件/核心组件
  - 新功能新特性
  - 优化现有功能
  - API 调整，可能存在不兼容更新
- **修订版本**
  - Bug 修复
  - 代码优化
  - 文档更新
  - 向后兼容的改动
