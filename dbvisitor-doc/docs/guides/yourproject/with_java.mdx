# 3.2 普通项目

普通 Java 项目是指不使用任何框架或容器的 Java 项目，它通常是一个简单的 Java 应用程序。

:::tip[提示]
dbvisitor 也可以很好的和任何 Java 项目整合使用，包括 Spring Boot、Quarkus 等，因此也可以在这些项目中手动创建 dbVisitor 入口对象。
:::

## 引入依赖

本指南对应开发版；SNAPSHOT 需从源码构建并安装到本地 Maven 仓库。版本选择见[引入依赖](./buildtools)。

依赖包，当前指南版本：<Highlight color="rgb(227 17 108)">{Vars.docsVersion}</Highlight>

```xml title='Maven 依赖'
<dependency>
  <groupId>net.hasor</groupId>
  <artifactId>dbvisitor</artifactId>
  <version>最新版本的版本号</version>
</dependency>
```

## 如何使用

在普通项目中使用 dbVisitor 只需要项目中可以提供 DataSource 或者 Connection 即可开始使用。

```java title='创建常用入口'
DataSource dataSource = ...;

JdbcTemplate jdbc = new JdbcTemplate(dataSource);

Configuration config = new Configuration();
Session session = config.newSession(dataSource);

LambdaTemplate lambda = new LambdaTemplate(dataSource);
```

dbVisitor 的 API 提供分为以下几种：
- dbVisitor 支持通过原始 SQL 方式利用 [编程式 API](../api/jdbc) 来访问数据库。
- dbVisitor 支持通过 [构造器 API](../api/lambda) 方式用同一种 API 来访问所有框架支持的数据库。
- dbVisitor 支持通过 [Mapper API](../api/mapper) 用 Java 接口组织数据访问层（含 BaseMapper 通用 CRUD）。
- dbVisitor 支持使用 [文件 Mapper](../api/file_mapper) 统一管理 SQL 语句。
