<span id="1-versions-and-dependencies" />

Requires Java 17 or later. Choose Maven or Gradle.

## Maven

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>jdbc-milvus</artifactId>
    <version>@project.docsVersion@</version>
    <classifier>all</classifier>
</dependency>
```

## Gradle

```groovy
repositories { mavenCentral() }
dependencies { implementation "net.hasor:jdbc-milvus:@project.docsVersion@:all" }
```


After adding the dependency, [connect to the database](./connection.mdx).
