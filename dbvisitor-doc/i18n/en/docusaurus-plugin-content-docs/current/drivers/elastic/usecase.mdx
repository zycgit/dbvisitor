## Dependencies and Versions

This page applies to `6.7.1-SNAPSHOT` and requires Java 17+ to build and run. For other versions, read the corresponding documentation.

Current source publishes an `all` classifier (relocated ANTLR, with other dependencies still transitive). Install locally from the repository root first:

```bash
./gradlew :dbvisitor-driver:publishToMavenLocal :jdbc-elastic:publishToMavenLocal
```

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>jdbc-elastic</artifactId>
    <version>6.7.1-SNAPSHOT</version>
    <classifier>all</classifier>
</dependency>
```

```groovy
repositories { mavenLocal(); mavenCentral() }
dependencies { implementation 'net.hasor:jdbc-elastic:6.7.1-SNAPSHOT:all' }
```

The SNAPSHOT dependency above is resolved from your local Maven repository.

## JDBC Connection
```java
String url = "jdbc:dbvisitor:elastic://127.0.0.1:9200";
Properties props = new Properties();
props.setProperty("user", "elastic");
props.setProperty("password", "changeme");
props.setProperty("connectTimeout", "5000");
props.setProperty("socketTimeout", "10000");
Connection conn = DriverManager.getConnection(url, props);
```

JDBC URL format:
```
jdbc:dbvisitor:elastic://{host}:{port}
```

Cluster example (multiple hosts):
```
jdbc:dbvisitor:elastic://host1:9200;host2:9200
```

Parameters may be supplied in the URL or Properties; see [Connection Parameters](./params.md). The driver class is `net.hasor.dbvisitor.driver.JdbcDriver`. Fragments below assume an open `Connection conn` and imports `java.sql.*` and `java.util.*`; close the connection when finished.

## Code Examples

### 1) Create index and mapping (DDL)
```java
try (Statement stmt = conn.createStatement()) {
    stmt.execute("PUT /my_index");
    stmt.execute("PUT /my_index/_mapping { \"properties\": { \"title\": { \"type\": \"text\" } } }");
}
```

### 2) Insert document (DML)
```java
try (Statement stmt = conn.createStatement()) {
    stmt.executeUpdate("POST /my_index/_doc/1 { \"user\": \"kimchy\", \"message\": \"hello\" }");
}
```

### 3) Search with `PreparedStatement` (DQL)
```java
String dsl = "POST /my_index/_search { \"query\": { \"term\": { \"user\": ? } } }";
try (PreparedStatement pstmt = conn.prepareStatement(dsl)) {
    pstmt.setString(1, "kimchy");
    try (ResultSet rs = pstmt.executeQuery()) {
        while (rs.next()) {
            rs.getString("_ID");
            rs.getString("_DOC");
        }
    }
}
```

### 4) Path placeholder `{?}`
```java
try (PreparedStatement pstmt = conn.prepareStatement("GET /my_index/_doc/{?}")) {
    pstmt.setString(1, "1");
    pstmt.executeQuery();
}
```

### 5) `_cat` nodes
```java
try (Statement stmt = conn.createStatement()) {
    stmt.executeQuery("GET /_cat/nodes");
}
```

## Multiple Commands and JDBC Results

```java
try (Statement stmt = conn.createStatement()) {
    boolean hasResult = stmt.execute("GET /my_index/_count; HEAD /my_index");
    while (true) {
        if (hasResult) {
            try (ResultSet rs = stmt.getResultSet()) {
                while (rs.next()) {
                    System.out.println(rs.getObject(1));
                }
            }
        } else {
            long count = stmt.getLargeUpdateCount();
            if (count == -1) {
                break;
            }
            System.out.println("updated=" + count);
        }
        hasResult = stmt.getMoreResults(Statement.CLOSE_CURRENT_RESULT);
    }
}
```

Use executeQuery for reads and executeUpdate or execute for writes. Semicolon-separated commands are consumed through execute/getMoreResults, not JDBC batch or a transaction. Hints go before the command; see [Command Reference](./commands.md) for all hints and limitations.
