<span id="dependencies-and-versions" />

Requires Java 17 or later. Choose Maven or Gradle.

## Maven

Set the `dbvisitor.version` property in your project POM to the driver version you use.

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>jdbc-mongo</artifactId>
    <version>${dbvisitor.version}</version>
    <classifier>all</classifier>
</dependency>
```

## Gradle

Set `dbvisitorVersion` in your project's `gradle.properties` to the driver version you use.

```groovy
repositories { mavenCentral() }
dependencies { implementation "net.hasor:jdbc-mongo:${dbvisitorVersion}:all" }
```


After adding the dependency, [connect to the database](./connection.mdx).
