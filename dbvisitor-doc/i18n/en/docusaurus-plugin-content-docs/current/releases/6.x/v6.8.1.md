# v6.8.1 (In Development)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>dbvisitor</artifactId>
    <version>6.8.1</version>
</dependency>
```

## Changes

- Milvus JDBC now supports single-value `SELECT` without `FROM`, including DataGrip's `SELECT 'keep alive'`. Constant queries execute locally. The new `PING` command probes server connectivity, returning `PONG` on success and raising an exception on failure.
- Fixed `@Query` methods returning `PageResult<T>` being treated as single-row queries. They now return page data and the total count, including a page wrapper for empty results.
- Fixed `jdbc-milvus`, `jdbc-mongo`, `jdbc-redis`, and `jdbc-elastic` publishing only an `all` classified artifact without a default JAR. The main driver artifact includes the relocated ANTLR runtime; database SDKs remain transitive dependencies.

## Upgrade Notes

- When upgrading these four JDBC drivers from 6.8.0 to 6.8.1, remove `<classifier>all</classifier>` from Maven dependencies, or the trailing `:all` from Gradle dependencies. Existing 6.8.0 artifacts still require that classifier.
- JDBC URLs, driver class names, and API usage are unchanged. For tools such as DataGrip that manage JARs manually, replace the old driver JAR and retain the required runtime dependencies.
