# v6.8.1 (2026-09-18)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>dbvisitor</artifactId>
    <version>6.8.1</version>
</dependency>
```

## Changes

- New Features
  - Milvus JDBC supports single-value `SELECT` without `FROM`, executing constant queries such as DataGrip's `SELECT 'keep alive'` locally.
  - Milvus JDBC adds `PING` to probe server connectivity, returning `PONG` on success and raising an exception on failure.
  - `jdbc-milvus`, `jdbc-mongo`, `jdbc-redis`, and `jdbc-elastic` add an `alone` package containing runtime dependencies for use in SQL clients.
- Bug Fixes
  - Fixed `@Query` methods returning `PageResult<T>` being treated as single-row queries.
  - Fixed these four JDBC drivers publishing only an `all` classified artifact without a default JAR.
- Improvements
  - The default JARs of the four JDBC drivers embed and relocate the ANTLR runtime to reduce dependency conflicts.

## Upgrade Notes

- When using the default 6.8.1 package of these four JDBC drivers in Maven, remove `<classifier>all</classifier>`.
- When using the default 6.8.1 package of these four JDBC drivers in Gradle, remove the trailing `:all` from the dependency version.
- Existing 6.8.0 driver artifacts still require the `all` classifier.
- JDBC URLs, driver class names, and API usage remain compatible.
- SQL clients such as DataGrip and DBeaver can replace the old driver and its dependency JARs with the corresponding `alone` package.
