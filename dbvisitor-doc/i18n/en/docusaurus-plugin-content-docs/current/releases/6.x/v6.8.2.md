# v6.8.2 (In Development)

## Changes

- New Features
  - Hasor integration adds `SessionConfigurer(String sourceName)` and `getSourceName()` to simplify configuration for named data sources.
  - The documentation site adds Chinese and English `llms.txt` files with a project introduction and documentation index for AI tools.
- Bug Fixes
  - Fixed missing English sidebar translations for data source and driver sections.
- Improvements
  - Upgraded Cobble to `5.0.4`.
  - Expanded the One Access concept, the two-layer adapter architecture, and SQL/DSL guidance for `JdbcTemplate`, `LambdaTemplate`, and Mapper APIs.
  - Moved IDE code formatting profiles to the `community` directory.
