# 3.2 Plain Java Projects

“Plain Java project” means a project without any framework or container—just a simple Java app.

:::tip[Tip]
dbVisitor integrates well with any Java project, including Spring Boot and Quarkus, so you can treat those as plain projects too.
:::

## Dependencies

the dependency, current version: <Highlight color="rgb(227 17 108)">{Vars.lastReleaseVer}</Highlight>

```xml title='Maven dependencies'
<dependency>
  <groupId>net.hasor</groupId>
  <artifactId>dbvisitor</artifactId>
  <version>latest version</version>
</dependency>
```

## How to use

To use dbVisitor in a plain project, just provide a `DataSource` or `Connection`.

```java title='Create common entry points'
DataSource dataSource = ...;

JdbcTemplate jdbc = new JdbcTemplate(dataSource);

Configuration config = new Configuration();
Session session = config.newSession(dataSource);

LambdaTemplate lambda = new LambdaTemplate(dataSource);
```

dbVisitor APIs you can choose from:
- Use raw SQL via the [Programmatic API](../api/jdbc).
- Organize data access as Java interfaces via the [Mapper API](../api/mapper).
- Use the unified [Fluent API](../api/lambda) across supported databases.
- Use predefined methods in [BaseMapper](../core/mapper/about#base-mapper) for common operations.
- Use [Mapper File](../api/file_mapper) to centrally manage SQL.
