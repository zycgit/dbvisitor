# @Delete Annotation

Marks an interface method to execute a DELETE statement.

:::info
`value` supports string arrays. Elements are joined with spaces, convenient for multi-line writing.
:::

```java title='Example: delete a user by id'
@SimpleMapper
public interface UserMapper {
    @Delete({"delete from users ",
             "where id = #{userId}"})
    int deleteUserById(@Param("userId") int userId);
}
```

## Properties

| Property | Description |
|---|---|
| value | <TagRed/> The DELETE statement to be executed. |
| statementType | <TagGray/> JDBC execution mode. Default `Prepared`<br/> - `Statement` → `java.sql.Statement`<br/> - `Prepared` → `java.sql.PreparedStatement`<br/> - `Callable` → `java.sql.CallableStatement` |
| timeout | <TagGray/> Execution timeout in seconds. Default `-1` |
