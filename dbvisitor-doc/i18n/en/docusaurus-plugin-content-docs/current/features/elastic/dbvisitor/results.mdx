# Result Reading

Document queries expose the original document in _DOC. With the default preRead=true, fields are also expanded for entity mapping.

## Read a Field by Name {#pre-read}

The first column is _ID, not the first business field. When reading one value, specify its column name instead of relying on column order:

```java
List<String> names = jdbc.queryForList(
        "POST /user_info/_search {\"query\":{\"term\":{\"uid\": ?}}}",
        new Object[] { "1001" },
        (rs, rowNum) -> rs.getString("name"));
```

With preRead=false, read the original document instead of expecting expanded columns:

```java
List<String> documents = jdbc.queryForList(
        "POST /user_info/_search {\"size\":10,\"query\":{\"match_all\":{}}}",
        (rs, rowNum) -> rs.getString("_DOC"));
```

Nested objects and arrays remain JSON strings. Configure JSON mapping when the entity uses structured Java properties.

## Limit the Returned Data

The driver reads only this REST response. Set size or use [Pagination](pagination.mdx); queryForList does not automatically fetch all search pages.

For JSON-to-object mapping, see [JSON Field Mapping](../../../guides/core/mapping/json-field.md).
