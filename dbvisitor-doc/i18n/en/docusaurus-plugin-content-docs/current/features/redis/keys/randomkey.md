:::info[Note]
Official reference: [RANDOMKEY](https://redis.io/docs/latest/commands/randomkey/).

Read a random key name from the current logical database.

## Syntax

```text
RANDOMKEY
```

## Results

| Return | Rows | Content |
| --- | --- | --- |
| ResultSet | 1 | KEY field, STRING type |

## Example

```text
RANDOMKEY
```
