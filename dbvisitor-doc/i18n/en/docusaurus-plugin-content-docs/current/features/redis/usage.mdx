# Data Reads and Writes

Redis commands and SQL statements use the same dbVisitor execution APIs. Write GET or SET directly; do not translate them into SELECT or INSERT. Redis uses JdbcTemplate and Mapper APIs, not the Fluent API or BaseMapper.

## Write, Read, and Delete a Key {#exec-command}

```java
JdbcTemplate jdbc = new JdbcTemplate(dataSource);
jdbc.executeUpdate("SET ? ?", new Object[] { "user:1001:name", "mali" });
String name = jdbc.queryForString("GET ?", "user:1001:name");
jdbc.executeUpdate("DEL ?", "user:1001:name");
```

SET replaces the existing value at the key. GET returns a result; SET and DEL return update counts. Connection setup is described in [JDBC Redis](../../drivers/redis/connection.mdx).

## Mapper Commands

<Tabs>
<TabItem value="annotation" label="Method Annotations" default>

```java
@SimpleMapper
public interface NameMapper {
    @Insert("SET #{key} #{name}")
    int save(@Param("key") String key, @Param("name") String name);

    @Query("GET #{key}")
    String load(@Param("key") String key);

    @Delete("DEL #{key}")
    int remove(@Param("key") String key);
}
```

</TabItem>
<TabItem value="xml" label="Mapper File">

```xml
<mapper namespace="com.example.NameMapper">
    <insert id="save">SET #{key} #{name}</insert>
    <select id="load" resultType="java.lang.String">GET #{key}</select>
    <delete id="remove">DEL #{key}</delete>
</mapper>
```

```java
@RefMapper("/mapper/redis-name.xml")
public interface NameMapper {
    int save(@Param("key") String key, @Param("name") String name);
    String load(@Param("key") String key);
    int remove(@Param("key") String key);
}
```

Save the XML at /mapper/redis-name.xml; NameMapper belongs to com.example.

```java
Session session = new Configuration().newSession(dataSource);
NameMapper mapper = session.createMapper(NameMapper.class);
mapper.save("user:1001:name", "mali");
String name = mapper.load("user:1001:name");
```

## A Write Can Return a Query Result

INCR changes a value but returns the new number. Use a query method to retrieve it:

```java
Long value = jdbc.queryForLong("INCR ?", "order:sequence");
```

In a Mapper, this command uses @Query, not @Update. Choose the API by the adapter's return form, not whether the command changes data. The same applies to ZADD and LPOP; see [Command Syntax](./syntax/index.md).

## Read a Hash as a Map

```java
jdbc.executeUpdate("HSET ? ? ?", new Object[] { "user:1001", "name", "mali" });
Map<String, String> fields = jdbc.queryForPairs(
        "HGETALL ?", String.class, String.class, "user:1001");
```

HGETALL exposes FIELD and VALUE columns, so queryForPairs is appropriate. For storing a whole object as JSON, see [JSON Field Mapping](../../guides/core/mapping/json-field.md); SET/GET store and retrieve that JSON string.

For multi-key writes, use MSET. It is one Redis command, not JDBC batch; separate SET calls are not a transaction.
