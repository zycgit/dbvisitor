# MongoDB Features

dbVisitor accesses MongoDB data sources via the [JDBC-Mongo](../../drivers/mongo/about) driver, based on the JDBC protocol.

## Quick Overview of Differences

| Concern | MongoDB Behavior |
|--------|-------------|
| API Support | JdbcTemplate, Builder API, BaseMapper, Annotations, Mapper File |
| Primary Key Generation | `_id` generated by MongoDB or the application; JDBC flag-based backfill is supported, and Mapper keyColumn must be omitted |
| Pagination | Paginated via Page object |
| Batch Writes | executeBatch not supported |
| Stored Procedures | Not supported |
| Object Mapping | Supported (need `ObjectId(?)` template for `_id` queries) |

**Not supported:** executeBatch, Stored Procedures

## Concept Analogy

Execution results of different MongoDB commands fall into two categories:
- **Update count** — analogous to INSERT/UPDATE/DELETE, obtained via `executeUpdate`
- **Single/Multi-row results** — analogous to SELECT result sets, find/search results expose `_ID` and `_JSON`; pre-read also expands document fields. Other commands have their own result columns
